## Audio Note Feature Implementation

### Overview
The audio note feature allows users to:

- Record voice notes directly in the app
- Save audio as attachments to notes
- Transcribe audio to text
- Play, pause, and manage recordings
- Share audio notes
- Control playback speed
- View recording and playback progress

### Technical Requirements

1. **Recording Interface**
   - Dedicated "Record Audio" button
   - Visual feedback during recording
   - Timer for recording duration
   - Waveform visualization

2. **Audio Management**
   - Save recordings as note attachments
   - Transcription of audio content
   - Audio playback controls
   - Playback progress tracking
   - Elapsed time display
   - Speed control (1x, 1.5x, 2x)
   - Delete audio attachments

3. **User Experience**
   - Clear recording state indicators
   - Intuitive playback controls
   - Consistent visual feedback
   - Accessible navigation
